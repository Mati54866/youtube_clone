## <a name="overview">✨ Overviews</a>

This YouTube Clone application delivers a seamless video browsing experience with a sleek, modern interface. Built with industry best practices, it replicates core YouTube functionalities including video search, channel browsing, and detailed video views.

> 🎯 **Perfect for:** Learning React, API integration, and building real-world applications.

---

## <a name="tech-stack">🛠️ Tech Stack</a>

| Technology | Purpose |
|------------|---------|
| **React JS** | Frontend library & component architecture |
| **Material UI 5** | UI components & styling |
| **React Router** | Navigation & routing |
| **Axios** | HTTP requests & API calls |
| **RapidAPI** | YouTube Data API v3 integration |

## <a name="features">🔋 Key Features</a>

| Feature | Description |
|---------|-------------|
| 📺 **Trending Videos** | Browse the latest trending content |
| 🔍 **Smart Search** | Search videos with debounced input |
| 🎥 **Video Details** | Watch videos with recommended content |
| 📺 **Channel Pages** | Explore channels and their video lists |
| 🌓 **Dark/Light Theme** | Toggle between themes seamlessly |
| 📱 **Fully Responsive** | Optimized for all screen sizes |
| 🏷️ **Category Browsing** | Filter videos by category |
| ⚡ **Debounced Search** | Optimized search performance |

## <a name="quick-start">🚀 Quick Start</a>

### 📋 Prerequisites

- [Git](https://git-scm.com/)
- [Node.js](https://nodejs.org/) (v14 or higher)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)
- [RapidAPI Key](https://rapidapi.com/) (YouTube v3 API)

### 📥 Installation

```bash
# Clone the repository
git clone https://github.com/Mati54866/youtube-clone.git

# Navigate to project
cd youtube-clone

# Install dependencies
npm install
# or
yarn install

# Create .env file and add your API key
echo "REACT_APP_RAPID_API_KEY=your_api_key_here" > .env

# Start development server
npm start
# or
yarn start
